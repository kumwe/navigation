# Integration

A host installs the exact verified release and supplies implementations of public ports where applicable. Package methods never grant authority; authorize before invoking persistence or returning data. Preserve caller transaction and optimistic-concurrency boundaries.

Read [source-map.json](source-map.json) for every namespace replacement. Delete old production declarations and move their behavior tests to this package only after release verification. Keep host service, database, trust/lifecycle, delivery, browser, recovery and composition tests in App. No aliases or dual PSR-4 roots are supported.
